## 常见「看起来没问题其实有问题」清单

| 症状 | 真正的病根 |
|---|---|
| 渲染很慢，一张要几分钟 | 其实是长请求假死，不是慢 —— 拆成逐视角请求 |
| 「保存成功」但目标文件没变 | `save` 路径用了 Ruby 插值，存到了 `~/Documents` |
| 整户家具/构件消失 | 镜像后 min/max 未重排，`box` 全部返回 nil |
| 模型比图纸高/深出一截 | 某个构件坐标轴转置（查 Z 坐标是否有 16000+ 的异常值） |
| 材质数量比声明少 | `purge_unused` 静默清除，有构件漏赋材质 |
| 尺寸差正好 240 / 120 | `y_north` 是外皮还是轴线搞混了 |
| 预览图中文全方块 | matplotlib 没指定中文字体（DXF 本身没问题） |
| 生成的脚本报 end-of-input | Python `return X` 换行接 `+ Y`，后半段被静默丢弃 |
| **校验全绿但尺寸全错** | **A~D 只验三方自洽，不验数字对错。加 E 段溯源审计 + fidelity_report** |
| **解出的相机高是负数** | **地平线测错了。屏幕中线不是地平线（只有光轴水平时才重合）** |
| **地平线 RMS 残差很大** | **线族在三维里不平行（池岸是弧形）。换建筑楼板线族** |
| **矫正出来的尺寸明显不对** | **warp_ratio 太大，或你矫正了 AIGC 图的远端面** |
| **量出来的人只有 15px 高** | **锚点分辨率不足，总误差 >20%。找 ≥100px 的近景锚点** |
| **HTML 报告报 unsupported format character** | **`%` 格式化撞上 CSS 的 `%` 或正文的「±10%」。改用 f-string** |
| **JSON 报 float32 not serializable** | **`json.dump` 要加 `default=float`** |
| **Image.transform 报 coeffs 错** | **Pillow ≥10 改了 API。用 numpy 逆映射自建（见 img_probe.py）** |
